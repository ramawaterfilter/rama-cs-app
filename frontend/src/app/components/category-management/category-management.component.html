Bulk Update / Create Categories

Upload your RAMA Customer Category Sheet as a CSV. Each row contains one complete category path. Maximum 1,000 rows and 1 MB per file.

Required columns: Type of Query, Query Category, Sub Category, Child Category. Fill in all four values on every row.

Query types and categories are matched by name. Missing entries and parent links are created automatically. Existing categories and links are preserved; uploading the same file again does not create duplicates.

Using an older ID-based CSV?

Older files with name and optional id, type, query_type_id, parent_ids are also supported. Keep an ID to update a category; leave it blank to create. Blank fields preserve existing values. Separate parent IDs with semicolons; use - to remove all parents.
